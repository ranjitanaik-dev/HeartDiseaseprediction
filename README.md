# ❤️ Heart Disease Prediction System

## Overview

A Machine Learning-based healthcare application that predicts the likelihood of heart disease using patient health parameters. The system helps demonstrate the application of AI and predictive analytics in healthcare.

## Features

* Heart disease risk prediction
* Data preprocessing and analysis
* Machine Learning model training
* Prediction based on user inputs
* User-friendly interface

## Tech Stack

* Python
* Pandas
* NumPy
* Scikit-learn
* Matplotlib
